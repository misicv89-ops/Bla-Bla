# Bla Bla New — sajt

Jedan responzivni fajl (`index.html`) — isti sajt za desktop i mobilni.

## Objavljivanje na GitHub Pages
1. Napravite novi repozitorijum na GitHub-u.
2. Otpremite sve fajlove iz ovog foldera u koren repozitorijuma.
3. Settings → Pages → Source: „Deploy from a branch“, grana `main`, folder `/ (root)`.
4. Sajt će biti na `https://<korisnik>.github.io/<repo>/`.

Pre objave: u `sitemap.xml`, `robots.txt` i `<meta property="og:url">` zamenite `https://www.example.com/` pravim domenom.
